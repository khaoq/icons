# icons

Icons for khaoq's Unraid Docker templates. Unraid downloads template icons without signing in, so they live in this public repo while the projects stay private.

| File | Used by |
|---|---|
| `arcgate.png` | Arcgate node templates (`khaoq/arcgate`, `deploy/unraid-arcgate-node*.xml`) |
| `routiq.png` | Routiq template (`khaoq/routiq`, `unraid/routiq.xml`) |

Template URL: `https://raw.githubusercontent.com/khaoq/icons/main/<file>`
